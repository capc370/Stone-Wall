# Камень преткновения
Мой первый проект. Работал над созданием первой версии примерно 3 месяца. Об игре: в центре мира стоит монолит. Со всех сторон света идут враги. Мы добываем ресурсы, создаем снаряжение и строим, чтобы не дать врагам сломать монолит. Рекомендую сразу заходить в Помощь в меню паузы, иначе ничего не поймете. Планируется дальнейшая поддержка игры и поиск художника для спрайтов.
